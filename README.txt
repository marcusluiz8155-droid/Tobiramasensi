TOBIRAMA SENSI — PROJETO ANDROID (protótipo)

O que contém:
- Bolinha flutuante que pode ser arrastada.
- Toque na bolinha para abrir/fechar o painel.
- Opções visuais: Calibrar mira, HS Capa, Mira sem tremer e Modo leve.
- Tema roxo/preto.

IMPORTANTE:
Este é um projeto-fonte Android, não um APK pronto. Para gerar o APK:
1. Instale o Android Studio em um computador.
2. Abra a pasta TobiramaSensiAndroid no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Use Build > Build Bundle(s) / APK(s) > Build APK(s).
5. No Android, instale o APK gerado e abra o app.
6. Toque em ATIVAR BOLINHA FLUTUANTE e permita "Exibir sobre outros apps".
7. Volte ao app e toque no botão para iniciar.

Os botões do painel são demonstrativos: não alteram a mira, não leem posições de jogadores,
não acessam memória do Free Fire e não contornam o anticheat.
